# Customer Shopping Behaviour Analysis

## Project Overview
This project analyzes customer shopping behaviour using Python, MySQL, and Power BI. The objective is to understand purchasing patterns, customer preferences, spending habits, subscription trends, and product performance to generate meaningful business insights.

The project uses a dataset containing 3,900 customer shopping records to perform data cleaning, exploratory data analysis, SQL-based business analysis, and interactive dashboard development.

## Tools & Technologies
- **Python:** Data cleaning, preprocessing, and exploratory data analysis using Pandas.
- **MySQL:** SQL queries to analyze customer behaviour and answer business questions.
- **Power BI:** Interactive dashboard development and data visualization.
- **VS Code:** Python script development and execution.

## Project Workflow

### 1. Data Cleaning & Preparation
- Loaded and explored the dataset using Pandas.
- Identified missing review ratings and handled them using the median rating of the corresponding product category.
- Standardized column names using snake_case.
- Created age groups and purchase frequency features.
- Checked data consistency and removed a redundant column.
- Connected Python to MySQL and imported the cleaned data for further analysis.

### 2. SQL Business Analysis
Used MySQL queries to investigate:
- Revenue generated by gender.
- High-spending customers who used discounts.
- Top-rated products.
- Purchase amount comparisons by shipping type.
- Subscribers versus non-subscribers.
- Products with the highest percentage of discounted purchases.
- Customer segmentation into New, Returning, and Loyal customers.
- Top three products in each category.
- Repeat purchases and subscription behaviour.
- Revenue contribution by age group.

### 3. Power BI Dashboard
Developed an interactive dashboard to visualize key shopping metrics and business insights, including:
- Total number of customers.
- Average purchase amount.
- Average review rating.
- Customer subscription status.
- Revenue by product category.
- Sales by product category.
- Revenue and sales by age group.

## Key Business Recommendations
- **Increase Subscription Adoption:** Highlight subscription benefits to encourage more customers to subscribe.
- **Improve Customer Retention:** Introduce loyalty programs and incentives for frequent shoppers.
- **Optimize Discount Strategies:** Evaluate discount effectiveness while considering profitability.
- **Promote Popular Products:** Highlight highly rated and frequently purchased products.
- **Personalize Marketing Campaigns:** Tailor promotions to relevant age groups and customer segments.
